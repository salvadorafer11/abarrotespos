## ISO 9001:2015 (vigente)
Sistema de gestión de la calidad de una organización (no de un producto de software). Enfoque a procesos y ciclo PHVA (planificar–hacer–verificar–actuar), pensamiento basado en riesgos. PENDIENTE: cómo se refleja en este proyecto (plan SQA = planificar, CI y pipeline = hacer, puerta de calidad y auditoría cruzada = verificar, registro de defectos y acciones correctivas = actuar).
